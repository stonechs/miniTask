# 同类 Windows CPU/系统负荷指示器

调查日期：2026-11-20。项目状态和功能可能随上游更新变化；资源数据仅记录项目公开自报值，没有统一环境复测。

| 项目 | 显示/交互形态 | 技术与范围 | 对本项目的参考 |
|---|---|---|---|
| [glint](https://github.com/Cyronius/glint) | 通知区域图标内的多条实时负荷条，右键勾选要显示的项目 | Rust/Win32，CPU、内存、GPU、NPU、磁盘、网络、温度；项目自报约 200 KB EXE、6.2 MB 私有内存、隐藏窗口 CPU 约一个核心的 0.05%–0.4% | 交互与图标最接近；复杂度和资源均高于本项目目标。 |
| [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor) | 托盘/任务栏显示，可右键菜单和设置项 | C++ 桌面工具，含网速、CPU、内存、硬件监控、插件等；标准/精简功能版本有区分 | 参考功能拆分及右键操作；精简核心功能可减少依赖。 |
| [rust-gauge](https://github.com/pino-lab-apps/rust-gauge) | Windows 托盘图标监视 CPU、内存、GPU、NPU，右键菜单 | Rust；GPU 读取描述为尽力通过 Windows PDH counters | 可研究 tray-first 的小型产品结构；公开首页未给出可统一比较的私有内存/EXE数据。 |
| [TaskbarStats](https://github.com/ericbruggema/TaskbarStats) | 浮动在任务栏通知区旁的监视组件，支持数字/仪表/条形和多种设置 | 多项 CPU/GPU/内存/网络/磁盘/电池/温度监控 | 对图形表达和设置有参考，但并非只用托盘图标，功能面宽。 |
| [Kinetik](https://github.com/WastedDesigner/Kinetik) | Windows 任务栏统计条和托盘入口 | 多种系统/硬件指标与图表 | 形态相近但产品范围明显更大，适合参考而非作为低开销基准。 |
| [SystemBarIndicator](https://github.com/coldneuro/SystemBarIndicator) | Windows 11 任务栏上的常驻统计条，托盘菜单 | CPU、内存、GPU、磁盘、网络及温度 | 主要面向任务栏覆盖/统计条，和通知区域单图标有实现差异。 |

## 结论

与 glint 类似的开源项目不少，但不少是多指标仪表盘、任务栏覆盖条或硬件监控套件；公开信息中缺少与本项目同样的 100 KB 私有内存、低于 20 KB 最终 EXE、低 CPU 目标的一致实测对比。因此可以借鉴交互和指标采样思路，不能仅凭“轻量”标签判断其资源成本。

对本项目更有价值的比较顺序：

1. glint：已按用户授权克隆到 `upstream/glint`，继续做源码级架构分析。
2. rust-gauge：托盘优先、指标范围有限，值得作为第二个源码参照。
3. TrafficMonitor：功能成熟但范围更大，重点参考其可选功能拆分。
