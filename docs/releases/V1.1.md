# miniTask V1.1

V1.1 将正式 x86 Crinkler 构建的哈希内存参数固定为 1 MiB，避免使用 Crinkler 默认的 500 MiB 配置。该版本仍提供四种架构与压缩组合：

| 文件 | 架构/压缩方式 | 大小 |
|---|---|---:|
| `miniTask-x86.exe` | x86，Clang `-Oz` | 12,800 B |
| `miniTask-x64.exe` | x64，GCC `-Os` | 14,336 B |
| `miniTask-x86-crinkler.exe` | x86，Crinkler 3.0b，`/HASHSIZE:1` | 5,113 B |
| `miniTask-x64-upx.exe` | x64，UPX 5.3.0 | 8,192 B |

Crinkler 版在 Windows 10 x64 测试机上以 High 优先级启动，工作集约 8.36 MiB，并正常退出；该版本需要 SSE4.2。UPX 自检通过。所有版本适用于 Windows 10 或更新版本。

构建四种文件：

```powershell
powershell -ExecutionPolicy Bypass -File build/release-all.ps1
```

本地快照目录为 `dist/V1.1/`；构建中间文件位于 `dist/V1.1/build-support/`。
